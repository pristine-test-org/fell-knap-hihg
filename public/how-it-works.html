How Fell Knap works

Fell Knap keeps one shared list for your whole team. Add an item, tick it off when it is done, and everyone sees the change the next time they open the page.

  1. Add an item to the shared list.
  2. Tick it off when it is finished.
  3. Open the page to see the latest list.

The list shows the five most recent items.
